# SQL Sales Analysis

This project analyzes sales data using SQL to extract meaningful insights.

## Key Analysis Performed
- Total Sales
- Total Orders
- Average Order Value
- Sales by Region
- Top Customers
- Customer Ranking using Window Functions

## Tools Used
- MySQL
- phpMyAdmin
